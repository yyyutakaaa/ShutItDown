        Shut down when I leave home

        Your iPhone turns the PC off when you leave, but only if nobody used it in the last 10 minutes.

        1. Open the Shortcuts app, go to Automation and tap +.
        2. Choose Leave, pick your home, choose Run Immediately, then Next and New Blank Automation.
        3. Add the action Get Contents of URL and paste this URL:
        4. Tap the arrow to show more. Set Method to POST.
        5. Under Headers, add one. Key: X-Device-Token Value (this phone's key, keep it private): ••••••••
        6. Set Request Body to JSON and add two Number fields: delayMinutes = 0 and onlyIfIdleMinutes = 10.
